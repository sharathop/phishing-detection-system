How PhishGuard Works

From URL input to threat verdict — here's the complete detection pipeline

Step 1
URL Input
User submits any suspicious URL through the PhishGuard interface for analysis.

Step 2
Feature Extraction
86 lexical and external features are extracted: URL length, dots, hyphens, HTTPS, suspicious keywords, IP detection, subdomain depth and more.
Step 3
XGBoostClassifier Model
Features are fed into a XGBoostClassifier trained on 100k URLs.

Verdict & Explanation
